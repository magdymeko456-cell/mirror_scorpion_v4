# فهرس محتوى Mirror Scorpion

هذا المجلد هو **قناة توزيع عامة وخفيفة** لحزم المحتوى التي يختارها المستخدم داخل التطبيق. لا يعني ظهور اسم مصدر في الفهرس أن التطبيق نزّل محتواه؛ لا ينزّل التطبيق إلا حزمة حالتُها `available` وبعد تأكيد المستخدم والتحقق من `contentSha256`.

## البنية

| المسار | الغرض |
|---|---|
| `content_catalog/v1/index.json` | قائمة الأسماء والترتيب والنطاق واللغة والمصدر والترخيص والهاش ومسار الحزمة. |
| `content_catalog/packages/` | ملفات JSON صغيرة مستقلة، حزمة واحدة لكل ملف وإصدار. |
| `docs/content-package-schema-v1.md` | العقد الذي يجب أن تلتزم به الحزمة قبل إتاحتها. |

## سياسة النشر

تُرفع حزم المالك الأصلية أو المواد ذات الحقوق والمصادر الواضحة فقط. لا ترفع كتباً أو تفاسير أو نصوصاً دينية منسوخة أو ملفات صوت أو فيديو بلا تحقق من حق الاستخدام والمصدر. تظل أي حزمة ناقصة المصدر أو الترخيص في حالة `requires_review` من دون رابط تنزيل.

يقرأ التطبيق الفهرس من فرع `main` ليحصل على الأسماء والترتيب والحالات الحديثة، ثم يقرأ كل حزمة من وسم Git ثابت مثل `content-v1.0.0`. لذلك يمكن تحديث الفهرس من دون تحديث APK، بينما تبقى بايتات الحزمة المحددة ثابتة وقابلة للتحقق بالهاش. لا تشكل GitHub وحدها نظام توقيع؛ ستضاف توقيعات فهرس منفصلة قبل قبول مصادر خارجية حساسة أو واسعة.
