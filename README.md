# Mirror Scorpion v4 — Flutter

Mirror Scorpion v4 هو تطبيق Flutter بواجهة **Royal Dark** عربية يضم ستة أقسام: الترجمة، الحوار، المستندات والعدسة، القصص والإلهام، الألعاب، والإعدادات مع PRO.

## الحالة الحالية

تم إنشاء نواة Flutter نظيفة بدلاً من إعادة استعمال مشروع v2 الذي احتوى تبعيات غير منشورة وملفات تفعيل ضعيفة. تعرض لوحة البداية الكروت الستة ومساراتها، وتحوي ساعة شطرنج محلية ومعرّف تثبيت PRO محلياً. لا تعرض الواجهات ترجمة أو OCR أو تفعيل PRO على أنه مكتمل قبل ربط خدمة حقيقية.

## البناء

تولّد GitHub Actions مشروع Android باستخدام `flutter create`، ثم تنفذ `flutter pub get` و`flutter analyze` و`flutter test`، وبعدها تنشئ APK بالإصدار release. لا يتضمن المستودع مفاتيح خاصة أو ملفات توقيع.

لدى توفر Flutter محلياً:

```bash
./termux_prepare_flutter_v4.sh
```

يقوم السكربت بإيقاف آمن إذا وجد مفاتيح أو ملفات توقيع داخل الشجرة. في بيئات Termux التي لا تحتوي Flutter، استخدمها للتحرير ومراجعة Git فقط، واترك بناء APK إلى GitHub Actions.

## الأمان

تتحقق خدمة الخادم من باتش PRO الموقع بـ RSA-SHA256. لا يقوم العميل بإصدار رمز تفعيل ولا يحتفظ بمفتاح RSA الخاص أو بمفتاح سري مضمّن.

## خارطة النقل

التفاصيل المعمارية وخطة نقل الترجمة وOCR والقصص والفقاعة والألعاب موجودة في `docs/flutter-v4-migration-architecture.md` على جذر المستودع.
