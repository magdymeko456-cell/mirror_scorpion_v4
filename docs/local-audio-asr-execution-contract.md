# عقد التفريغ والترجمة الصوتية المحلية

## النطاق الفعلي

يعالج Mirror Scorpion ملف الصوت الذي **يختاره المستخدم** داخل هاتفه: يفحص الهاتف والملف، وينزل نموذج التفريغ مرة واحدة فقط بعد موافقة صريحة، ثم يفرغ الصوت محلياً، ويترجم النص إلى لغة الجهاز، وينشئ ملف WAV قابل للمشاركة. لا يرفع هذا المسار الملف أو النص المفرغ إلى خدمة خارجية، ولا يراقب ملفات أو حافظة أو تطبيقات أخرى.

> لا يعرض التطبيق «تم التفريغ» أو زر مشاركة ملف قبل وجود نص ناتج من المحرك أو وجود WAV فعلي أكبر من صفر بايت.

| المرحلة | السلوك المطبق |
|---|---|
| اختيار الملف | دبوس في محرر المصدر العلوي؛ يقبل MP3 وM4A وWAV وOGG وAAC وFLAC حتى 128 MB. |
| الموافقة | تظهر رسالة فيها اسم الملف وحجمه وخصوصية المعالجة، و142 MB لنموذج Whisper عند عدم وجوده. |
| توافق الهاتف | ميزة تفريغ الملفات فقط تتطلب 8 GB RAM أو أكثر و512 MB مساحة حرة على الأقل. بقية التطبيق لا تُغلق على الهواتف الأقل. |
| تثبيت النموذج | تنزيل إلى ملف جزئي، فحص الحجم وSHA-256، ثم إعادة تسمية ذرية إلى `ggml-base.bin`. |
| التفريغ | يستعمل `whisper_ggml` فوق whisper.cpp بمعالجة FFI خارج واجهة Flutter؛ لا يظهر زر إلغاء لا توقفه الحزمة فعلياً، ويمنع طلب موازٍ. |
| الترجمة | يمر النص المفرغ إلى ML Kit المحلي مع تحديد لغة المصدر تلقائياً، والهدف هو لغة الجهاز. |
| المشاركة | يصنع Android TTS ملف WAV من النص المترجم، ثم يفحص وجوده وحجمه قبل فتح واجهة مشاركة Android. |

## سلامة نموذج التفريغ

اعتمد الإصدار الأول نموذج Whisper base متعدد اللغات، لا نموذج إنجليزي فقط. حجم ملف GGML هو **147,951,465 بايت** وبصمته SHA-256 هي:

```text
3dd14eea856493d334349b405782ddcaf0028d4b5df4088345fba2efe
```

يرفض التطبيق ملف النموذج إذا اختلف الحجم أو البصمة، ويحذف الملف الجزئي. يحرر كذلك نسخة العمل الصوتية وWAV الوسيط بعد اكتمال التفريغ أو فشله. Whisper وwhisper.cpp مرخصان MIT؛ حزمة تحويل التنسيقات التي تأتي تبعياً مع طبقة Whisper تعلن LGPL-3.0، ويُضاف إشعارها قبل النشر. [1] [2] [3]

## إصلاح ميكروفون الحوار

عند تبديل المتحدث أو لغة المصدر، يوقف التطبيق جلسة التعرف السابقة وينتظر مهلة قصيرة لانتهائها قبل بدء جلسة جديدة بمعرف `localeId` مطابق للغة مثبتة في هاتف المستخدم. عند غياب اللغة، يعرض التطبيق اللغات المتاحة ولا يعود إلى العربية بصمت.

## حدود متعمدة

لا يعني هذا المسار نسخ صوت المستخدم أو تمييز المتحدثين أو توليد MP3. الأصوات الأربعة الحالية ملفات أداء فوق صوت Android المثبت، وليست نماذج صوت بشرية مضمونة. يظل نسخ صوت المستخدم وتمييز المتحدثين مرحلتين مستقلتين تتطلبان نموذجاً مرخصاً وتسجيل موافقة قابلة للحذف واختبار Android فعلياً.
