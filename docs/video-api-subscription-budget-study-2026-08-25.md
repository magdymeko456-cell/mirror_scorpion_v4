# دراسة ميزانية API الفيديو وخطة الاشتراك

**تاريخ الدراسة:** 25 أغسطس 2026
**السقف الذي طُرح للنقاش:** لا يزيد عن **20 دولاراً سنوياً** مع فيديو غير محدود لتطبيق منشور.

## النتيجة التنفيذية

لم أجد خطة موثقة تجمع بين API صالح لتطبيق منشور، وسقف أقل من 20 دولاراً سنوياً، وفيديو غير محدود فعلاً. الفيديو التوليدي يحاسب بالرصيد أو الطلب أو الحوسبة؛ واستخدام كلمة «غير محدود» في منتج استهلاكي لا يثبت حق API أو إعادة البيع أو تكلفة صفرية لكل المستخدمين. [1] [2] [3] [4]

> لا يجوز عرض «فيديو غير محدود» في Mirror Scorpion ما لم ينص عقد API صراحةً على ذلك ويغطي التطبيق المنشور. لا تثبت المصادر المراجعة هذا الشرط ضمن السقف المقترح.

| المزود | نموذج التكلفة المنشور | هل يحقق 20$/سنة وغير محدود؟ | القرار |
|---|---|---:|---|
| **Runware** | PAYG بلا اشتراك أو حد أدنى؛ الفيديو بحسب الاستخدام. [1] [2] | لا | المزود المختار مبدئياً، خلف Firebase فقط وبحد صفر حتى اعتماد الميزانية. |
| Fal | تسعير بحسب مخرج/مدة النموذج. [3] | لا | مسار مستبدل؛ لا يستخدم في الواجهة أو البوابة. |
| Pika API Club | عضوية شهرية ثم استهلاك PAYG. [4] | لا | غير مناسب للسقف. |
| Runway API | أرصدة لكل توليد. [5] | لا | غير مناسب لاشتراك غير محدود منخفض التكلفة. |

## قرار المنتج الحالي

Runware هو **المزود المختار مبدئياً** لأنه يوفر مسار API بالفوترة حسب الاستخدام، وليس لأنه يحقق سقفاً ثابتاً أو فيديو غير محدود. لا شراء ولا رصيد ولا حساب إنتاجي ولا مفتاح ولا نشر Firebase في هذه المرحلة.

| الحقل في الإعدادات | القيمة الحالية الصادقة |
|---|---|
| حالة الفيديو السحابي | غير مفعّل. |
| المزود المرشح | Runware، خلف خادم Firebase وليس داخل APK. |
| حد الفيديو | 0 مقطع حتى اعتماد الخطة والسقف. |
| التجديد | لا يوجد؛ لا تجديد تلقائي. |
| نسخ صوت المستخدم | غير مفعّل حتى موافقة وميزانية منفصلتين. |
| طريق الترقية | بعد اعتماد مزود وخطة وخصوصية وامتثال متجر ودفع. |

لا يبدأ التشغيل إلا بعد أن يحدد المالك عدداً صريحاً للسقف الشهري/السنوي والحصة اليومية والمدة والدقة والمنطقة ومدة الاحتفاظ. قبل ذلك، يبقى اختبار الجاهزية محلياً ولا يرسل نصاً أو صورة أو صوتاً.
