# ملاحظات توثيقية خارجية: التعرف على الكلام ولغة الجهاز

راجعت توثيق `speech_to_text 7.4.0` قبل تغيير قاعدة لغة الميكروفون.

| النتيجة | الأثر في التطبيق |
|---|---|
| تستعمل الحزمة اللغة الافتراضية للجهاز عندما لا يمرر التطبيق `localeId` صالحاً. | لا يسمح التطبيق بالرجوع الصامت إلى لغة عربية أو أي لغة افتراضية عند عدم مطابقة لغة المصدر. |
| توفر `SpeechToText.locales()` قائمة اللغات المثبتة في خدمة التعرف؛ ويقبل `listen` قيمة `localeId` من هذه القائمة. | يطابق التطبيق لغة الجهاز مع locale مثبت، ويعرض رسالة واضحة مع اللغات المتاحة إن لم يجد مطابقة. |
| التعرف مخصص للعبارات القصيرة وليس استماعاً دائماً، وقد تفرض Android مهلة قصيرة. | لا تدعي واجهة المايك الاستماع الدائم أو تفريغ ملفات صوت طويلة. |
| قد يعتمد التعرف في Android على خدمات النظام أو الشبكة. | رسالة الخصوصية توضّح أن التطبيق لا يسجل الصوت بنفسه ولا يحدد ما إذا كانت خدمة الجهاز محلية أو بعيدة. |

## المصادر

1. https://pub.dev/packages/speech_to_text/versions/7.4.0 — README للحزمة، قسم **Switching Recognition Language** وقيود Android.
2. https://pub.dev/documentation/speech_to_text/7.4.0/speech_to_text/SpeechToText/listen.html — توقيع `listen` وسلوك `SpeechListenOptions.localeId`.
