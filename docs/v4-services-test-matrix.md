# مصفوفة خدمات Mirror Scorpion v4 قبل بوابات PRO

## مبدأ التنفيذ

تعمل الخدمات أولاً في وضع اختبار صادق. لا تفتح الواجهة ميزة مدفوعة لمجرد اكتمال الشاشة؛ بل تعرض النتيجة الفعلية أو رسالة فشل مفهومة. بعد نجاح بناء APK واختبارات الخدمة على Android، تُحوّل كل ميزة إلى سياسة خطة مجانية/PRO داخل الخادم، لا إلى شرط مخفي في واجهة Flutter.

تتبع طبقات Flutter مبدأ فصل الواجهة عن مصدر البيانات: تعرض الشاشة الحالة، ويتولى مستودع البيانات التخزين والأخطاء وإعادة المحاولة، بينما تغلف الخدمة الطلبات الأصلية أو طلبات HTTP [1].

## مصفوفة الخدمات واختبارات القبول

| الخدمة | التنفيذ في وضع الاختبار | اختبار القبول قبل PRO | بوابة PRO بعد الاستقرار |
|---|---|---|---|
| ترجمة النص | ترجمة سحابية من خادم يحمي مفتاح المزود، مع تشغيل نموذج محلي عند توفر زوج لغات مدعوم | ترجمة نص عربي/إنجليزي وعربي/فرنسي، وإظهار خطأ شبكة بدلاً من نص بديل | حدود الاستخدام أو عدد اللغات/المحركات الأوسع فقط |
| الترجمة أوفلاين | تنزيل نموذج لغة وقياس حالته في التخزين | ترجمة دون اتصال بعد تنزيل النموذج وإظهار تقدم حقيقي | تنزيل عدد أكبر من الحزم أو الأزواج المتقدمة |
| التقاط الكلام والملف الصوتي | تسجيل محلي ثم إرسال الملف إلى خادم تفريغ وترجمة | ميكروفون، ملف صوت، إلغاء، حد حجم، وتفريغ فعلي قابل للتحرير | سقف الدقائق أو أصوات إضافية فقط |
| TTS والأصوات | أصوات نظام مثبتة أولاً، ثم مزود صوت خادمي إن اختير | تشغيل النص وإيقافه ومشاركة ملف صوتي موقّع | الأصوات الأربعة المميزة وصوت المستخدم بعد موافقة صريحة |
| نسخ الصوت | لا يبدأ قبل اختيار مزود وسياسة موافقة وحذف | إثبات موافقة المستخدم وحذف العينة وإخراج صوت تجريبي | الوصول المستمر إلى صوت المستخدم |
| العدسة وOCR للصورة | كاميرا وML Kit على الجهاز | صورة عربية/إنجليزية، نص قابل للنسخ، نتيجة خطأ واضحة | لا شيء مبدئياً؛ OCR الأساسي يجب أن يكون فعالاً للجميع |
| PDF والمستندات | رفع آمن للخادم وتحويل/OCR بعدد صفحات معلوم | ملف 1–5 صفحات، تقدم 3 ثوانٍ على الأقل، معاينة الأصل بالضغط المستمر، توقيع مائل | أكثر من 5 صفحات والحفظ إلى الجهاز |
| القصص والمراجع | JSON محلي ومصادر موثقة قابلة للتنزيل | فتح قصة، زر المزيد، إسناد المصدر، TTS، وضع دون اتصال بعد التنزيل | تنزيل مكتبات كاملة ووصول ممتد أوفلاين |
| الإلهام | LLM خلف خادم مع فلتر سلامة | رسالة مرتبطة بطلب المستخدم أو قراءة قصصه، مع رفض محتوى مسيء | إشعارات مخصصة وسقف أكبر للتوليد |
| فيديو القصة | مزود فيديو خارجي عبر طلب خادمي ومراقبة حالة | سيناريو، طلب فيديو، تقدم، رابط أو ملف صالح؛ لا عرض مشاهد نصية كفيديو | الرصيد اليومي ومدد الفيديو الأعلى |
| الشطرنج وروبيك | منطق محلي ومحرك لعب ومشهد مُختبر على هاتف | حركات قانونية، ساعة، منافس، تدوير مكعب وحل تعليمي | لا يوصى بقفل قواعد اللعب الأساسية |
| الفقاعة العائمة | خدمة Android foreground وOverlay بإذن صريح | تشغيل، سحب، إغلاق، Share/Process Text، عدم قراءة تطبيقات أخرى تلقائياً | تفعيلها كباقة بعد ثبات الاختبار فقط |
| PRO | باتش موقع يتحقق منه الخادم بمفتاح عام | جهاز صحيح، توقيع صحيح/خاطئ، انتهاء، انقطاع الشبكة ووقت خادم | تفعيل بوابات الميزات بعد اكتمال كل اختبار أعلاه |

## خيارات تشغيل الخدمات

لا يمكن تضمين مفاتيح الترجمة أو الذكاء أو الفيديو أو توقيع PRO في APK. يلزم اختيار طبقة خدمة واحدة قبل إرسال أي أسرار. كلا الخيارين التاليين قادر على استقبال ملفات وتشغيل تحقق RSA وتخزين مصادر القصص؛ الاختلاف في منظومة الإدارة والكلفة والتشغيل.

| النهج | ما يقدمه | التنازلات | الكلفة | تعقيد الإعداد |
|---|---|---|---|---|
| منصة Google/Firebase | وظائف HTTP وخدمات تخزين وقاعدة بيانات وإشعارات، وتكامل طبيعي مع ML Kit على Android | يحتاج مشروع Google وإعداد فوترة عند نشر وظائف الإنتاج، وخدمات AI/فيديو مدفوعة منفصلة | يبدأ بمستوى محدود ثم يعتمد على الاستهلاك والمزود | متوسط |
| Supabase | قاعدة PostgreSQL وتخزين ودوال TypeScript عند الحافة مع أسرار محمية وسجل طلبات | يحتاج مزوداً مستقلاً للترجمة وLLM وOCR/فيديو، ويلزم إعداد إشعارات مجدولة بعناية | مستوى محدود ثم استهلاك ومزودات AI خارجية | متوسط |
| خادم مخصص | تحكم كامل في الملفات والصفوف والطوابير ومزودات AI | يتطلب تشغيل ومراقبة وتحديثات أمنية دائمة، ولا يبدأ قبل تحديد الاستضافة | خادم ومزودات AI منفصلة | أعلى |

تدعم Firebase وظائف خلفية تستجيب لطلبات HTTP والأحداث والجدولة من دون إدارة خادم مستقل، لكنها تتطلب خطة دفع عند النشر الإنتاجي [2]. أما Supabase Edge Functions فهي دوال TypeScript قصيرة يمكنها حفظ الأسرار، استدعاء خدمات خارجية، ومعالجة رفع ملفات؛ ويجب نقل الأعمال الثقيلة والطويلة إلى عامل خلفي [3].

## قرار البنية المعتمد

تم اعتماد **Google/Firebase** لتثبيت عقود API ومكان الأسرار وتخزين ملفات الصوت/PDF والفيديو. تنشأ بيئة اختبار منفصلة عن الإنتاج، وتضاف المفاتيح عبر إعدادات البيئة فقط. لا يُربط الدفع أو أي بوابة PRO في هذه المرحلة.

## ملاحظات عن الخدمة المحلية

يدعم ML Kit معالجة النصوص على الجهاز ويمكنه العمل دون اتصال، كما يوفر التعرف على النص وترجمة محلية بين 58 لغة [4]. لذلك يستخدم للـOCR والترجمة الأوفلاين للأزواج التي يدعمها، بينما شرط 100 لغة يتطلب خدمة ترجمة سحابية أو مزوداً إضافياً. الرسائل كل 3 ساعات لا تعتمد على فتح التطبيق: يلزم نظام إشعارات أو جدولة خادمية، ولا تُبنى عبر فحص متكرر من التطبيق.
