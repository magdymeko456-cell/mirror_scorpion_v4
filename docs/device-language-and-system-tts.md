# لغة الجهاز وTTS النظامي

## ما أضيف في وضع الاختبار

تستخدم الترجمة لغة الجهاز كبداية عندما لا توجد تفضيلات محفوظة، ثم تحفظ آخر لغة مصدر وآخر لغة هدف بصورة مستقلة. تستخدم القصص لغة الجهاز كإشارة للبيانات المترجمة مستقبلاً؛ لا تتحول النصوص العربية الثابتة تلقائياً إلى لغة أخرى قبل إضافة ملفات ترجمة واجهة حقيقية.

يستخدم زر السماعة `flutter_tts` وصوت النظام المتاح على الجهاز. يمكن تشغيل النص أو إيقافه، وتظهر حالة صريحة إذا لم يكن صوت اللغة مثبتاً. لا يمثل هذا أيّاً من أصوات سيف أو سلمى أو سما أو سارة، ولا يستنسخ صوت المستخدم ولا ينشئ ملف مشاركة صوتي في هذه المرحلة.

| الاختبار | النتيجة المطلوبة |
|---|---|
| جهاز عربي مع هدف إنجليزي | تظل اللغة المختارة محفوظة بعد إعادة فتح التطبيق؛ ينطق النص الإنجليزي إذا كان صوت `en-US` متاحاً. |
| جهاز إنجليزي بلا تفضيل سابق | يبدأ مصدر الترجمة من `en` وهدف افتراضي `ar`. |
| صوت لغة غير مثبت | لا يتعطل التطبيق؛ تظهر رسالة أن صوت النظام غير متاح. |
| مغادرة كارت الترجمة أو القصص | يتوقف النطق. |

## حدود صادقة

تحتاج ترجمة واجهة التطبيق وبيانات القصص بلغة الجهاز إلى حزمة localisation ومحتوى مترجم موثوق، وهي ليست جزءاً من هذه الدفعة. ولا يبدأ توليد أو مشاركة ملف صوت أو أصوات مميزة أو نسخ الصوت قبل اختيار مزود خادمي وموافقة وسياسة حذف واضحة.
