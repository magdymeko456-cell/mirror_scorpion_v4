# أصول PDF والخط العربي

يستخدم مخرج المستند المترجم مكتبة `pdf` ومكتبة `printing` لإنشاء ملف PDF محلي وفتحه لخدمات مشاركة وطباعة النظام. لا تُرسل هذه العملية النص أو المستند إلى خادم.

| الأصل | الاستخدام | الرخصة والمصدر |
|---|---|---|
| `pdf` | إنشاء مخرج PDF متعدد الصفحات | [صفحة الحزمة](https://pub.dev/packages/pdf) — Apache-2.0 |
| `printing` | مشاركة PDF وفتحه في خدمة الطباعة | [صفحة الحزمة](https://pub.dev/packages/printing) — Apache-2.0 |
| Noto Naskh Arabic | تضمين العربية محلياً داخل ملف PDF | [مستودع Noto Arabic](https://github.com/notofonts/arabic) — SIL Open Font License 1.1 |

نسخة الرخصة الكاملة للخط موجودة في `assets/fonts/OFL.txt`، والخط المضمّن هو `assets/fonts/NotoNaskhArabic-VariableFont_wght.ttf`.
