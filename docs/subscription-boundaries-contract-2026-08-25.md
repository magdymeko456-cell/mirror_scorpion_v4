# عقد حدود الاشتراك والخدمات

**الحالة:** واجهة توضيحية فقط؛ لا يوجد شراء أو تجديد تلقائي أو سعر معتمد داخل التطبيق.

تشرح بطاقة الإعدادات الحدود الفعلية بدلاً من تسويق خدمة غير مفعّلة. لا تكتب كلمة «غير محدود» للفيديو، ولا تعرض سعراً سنوياً أو زر شراء ما لم يوجد عقد موثق وتمويل وسياسة متجر واضحة.

| القسم | ما يظهر للمستخدم | الحد الحقيقي |
|---|---|---|
| الأساسي المحلي | المحتوى المرخص وأصوات Android والترجمة على الجهاز حيث تتاح النماذج. | لا يعتمد على API فيديو أو رصيد سحابي. |
| PRO الموقّع | التحقق من رمز تفعيل موقع. | لا يشتري ولا يفتح خدمة فيديو تلقائياً. |
| فيديو Runware | «غير مفعّل — 0 مقطع يومياً». | لا مفتاح ولا رصيد ولا إرسال بيانات قبل قرار المالك. |
| استوديو الصوت | «غير مفعّل». | نسخ الصوت وتصدير MP3 يحتاجان موافقة ومزوداً وميزانية منفصلين. |

> لا تساوي نسخة PRO اشتراكاً سحابياً. ويتطلب كل مزود سحابي موافقة منفصلة وسجلاً للحصة والتكلفة والاحتفاظ والحذف.

يظل زر التفعيل الموقّع خاصاً بالرمز المحلي/الخادمي. ولا يظهر دفع فعلي أو تجديد أو حد فيديو موجب إلا بعد اعتماد المالك للسقف وسياسة الخصوصية والاحتفاظ.
