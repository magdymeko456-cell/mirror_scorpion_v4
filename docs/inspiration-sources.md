# مصادر ركن القصص والإلهام

هذه الروابط جرى التحقق من بنيتها قبل ربطها داخل الخادم. يجب إبقاء الإسناد ظاهراً للمستخدم وعدم حذف بيانات المصدر عند التخزين المحلي.

| الاستخدام | المصدر | الرابط | ملاحظات |
|---|---|---|---|
| تفسير وإصدارات متعددة | spa5k/tafsir_api | https://github.com/spa5k/tafsir_api | المستودع يذكر ترخيص MIT ويعرض CDN للإصدارات داخل `tafsir/`، ومنه استُخدم إصدار الجلالين الإنجليزي ومصدر أسباب النزول كروابط أولية قابلة للمراجعة |
| قصص الأنبياء وفهرس 25 نبياً | mohammed-2-5/islamic-library-data | https://github.com/mohammed-2-5/islamic-library-data | README يعرّف `prophet_stories/index.json` وملفات القصص الكاملة؛ يجب مراجعة الترخيص النهائي قبل أي توزيع تجاري |
| مثال مصدر قصصي متعدد اللغات | rasenga223/qalb-islamic-stories | https://github.com/rasenga223/qalb-islamic-stories | المستودع يعرّف بنية `stories.json` ويذكر MIT؛ لا يُعامل كمرجع ديني بذاته بل كمصدر بيانات وصفية |
