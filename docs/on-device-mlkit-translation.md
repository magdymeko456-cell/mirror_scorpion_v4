# الترجمة المحلية عبر ML Kit

## نطاق المرحلة

أضيفت خدمة ترجمة نصية محلية لا تعتمد على Cloud Functions. تحدد الخدمة لغة النص أولاً، وتتحقق من دعم لغة المصدر والهدف، ثم تطلب تنزيل النموذجين عند الحاجة وتترجم النص على Android أو iOS فقط. لا تضع الواجهة نصاً بديلاً عند فشل التحديد أو عدم دعم اللغة أو فشل تنزيل النموذج.

| الخاصية | السلوك |
|---|---|
| تعريف لغة المصدر | ML Kit Language Identification بحد ثقة 0.5 |
| ترجمة النص | ML Kit On-Device Translation |
| التنزيل الأول | يحتاج اتصالاً لتنزيل نموذجَي المصدر والهدف |
| العمل لاحقاً | يعتمد على بقاء النماذج المحمّلة على الجهاز |
| اللغات | تدعم ML Kit أكثر من 50 لغة، وليست كل اللغات المعروضة في القائمة البصرية |
| المنصات | Android وiOS فقط؛ لا يتم الادعاء بدعم الويب |

## قاعدة الصدق

إذا اختار المستخدم لغة غير مدعومة محلياً، أو لم يحدد المحرك لغة المصدر، أو تعذر تنزيل نموذج، تعرض الواجهة السبب وتمسح حقل المخرجات. لا تستدعي خدمة خادم غير منشورة، ولا تضع ترجمة مزيّفة.

## اختبار Android المطلوب لاحقاً

1. أدخل نصاً عربياً قصيراً ثم اختر الإنجليزية، وتأكد من ظهور تنزيل النماذج أول مرة فقط.
2. أوقف الإنترنت بعد اكتمال التنزيل وأعد الترجمة للتحقق من السلوك المحلي.
3. اختر لغة غير مدعومة في ML Kit وتأكد من ظهور الحالة الصادقة بلا مخرجات.
4. اختبر تحديد لغة لاتينية ثم ترجمتها إلى العربية.
