# مواصفة قبول واجهة ووظائف Mirror Scorpion v4

## قاعدة الحماية

تُبنى الواجهة الخارجية من المرجع الناجح أولاً: خلفية كحلية متدرجة، عقرب معدني نابض مع انعكاس، عنوان وهوية ثابتة، مفتاح الفقاعة، ثم شبكة عمودين من الكروت الستة. لا يُضاف تبويب رئيسي أو قائمة بديلة أو إعادة ترتيب للكروت. توضع الميزات داخل صفحات الكروت فقط.

## اللوحة الرئيسية

| العنصر | مواصفة القبول |
|---|---|
| شعار العقرب | صورة العقرب المرجعية داخل دائرة مضيئة 140×140 تقريباً، بنبضة 3 ثوانٍ وانعكاس سفلي هادئ. |
| العنوان | `ميرور سكربيون` بالسيان وعبارة `حيث تُصنع البدايات` أسفله. |
| الفقاعة | كبسولة حالة ومفتاح تشغيل/إيقاف تحت العنوان. عند عدم ربط خدمة Android تعرض بوضوح أن النظام سيطلب إذن الظهور فوق التطبيقات؛ لا تدّعي تشغيلها. |
| الكروت | عمودان، تباعد 16، ترتيب ثابت: ترجمة نصية، حوار مترجم، مستندات وعدسة، قصص وإلهام، ألعاب 3D، إعدادات. |
| الألعاب | تفتح ورقة سفلية لاختيار شطرنج 3D أو روبيك 3D. |

## كارت 1: الترجمة النصية

يوضع اختيار اللغة في منتصف الجزء العلوي، ويستعيد آخر لغات المستخدم المحفوظة. يجمع تطبيق البداية قائمة لغات مثبتة؛ لا يكتب على الواجهة `100 لغة` إلا بعد ربط المصدر الفعلي للقائمة.

| العنصر | السلوك المطلوب | حالة المرحلة الحالية |
|---|---|---|
| المحرر العلوي | يستقبل النص أو التفريغ من الميكروفون، ويظل قابلاً للتحرير. النقر بعد اكتمال عملية سابقة يبدأ جلسة جديدة ويمسح المحررين. | واجهة أولية فقط |
| المحرر السفلي | يعرض استجابة خدمة الترجمة لا نصاً مصطنعاً. | ينتظر API |
| الميكروفون | تسجيل وتفريغ فعلي ثم تحرير للغة المصدر. | ينتظر `record` وWhisper/API |
| الدبوس | اختيار ملف صوت من الجهاز أو share intent، ثم تفريغ وترجمة حقيقية. | ينتظر `file_picker` وAPI |
| أسفل المخرج | نطق، مشاركة ملف صوت مترجم وتوقيع التطبيق، ونسخ النص. | ينتظر TTS/توليد الصوت/Share |

## كارت 2: الحوار المترجم

يستخدم مربعين كبيرين لإظهار الكلام الملتقط والترجمة. يبقى زر اللغة الموجود يمين شريط التحكم دائماً لغة الإدخال، حتى بعد استخدام التبديل؛ ويصبح زر اليسار لغة الإخراج. يحتوي الشريط على لغة المصدر، سهم تبديل، ميكروفون واضح، ولغة الهدف، مع دبوس ملف صوتي. الضغط التالي على الميكروفون يبدأ محادثة جديدة ويمسح الطرفين. لا تظهر الترجمة إلا من خدمة حقيقية.

## كارت 3: المستندات والعدسة

| العنصر | مواصفة القبول |
|---|---|
| العدسة | كاميرا وOCR فقط، من دون فتح بحث ويب. توجد قائمة لغة في أسفل اليمين. |
| المستندات | حقل رابط، زر بحث، زر أكبر لفتح مستعرض الملفات، ثم يعرض مسار الملف المختار تلقائياً. |
| الترجمة | زر كبير يفتح وضع ملء الشاشة؛ يظهر الأصل مع تقدم لا يقل عن 3 ثوانٍ، ثم تغطيه ورقة الترجمة من اليمين. الضغط المستمر يكشف الأصل، ورفع الإصبع يعيد الترجمة. |
| الحقوق والخطة | تحتوي الورقة توقيعاً مائلاً شبه شفاف: `ترجم هذا المستند بواسطة ميرور سكربيون`. المجاني يحدّ بخمس صفحات؛ الحفظ إلى الجهاز ووثائق غير محدودة يتطلبان PRO. |
| المشاركة | مشاركة الناتج فقط بعد نجاح OCR والترجمة، لا عند وجود خطأ. |

## كارت 4: الأحاديث والقصص والإلهام

تظهر الأحاديث القدسية عشوائياً من بيانات محلية، بخط قابل للقراءة وصوت قراءة. يعرض كل مصدر قصة معنونة وملخصاً قصيراً وزر `المزيد`. يفتح المزيد المحتوى الأصلي داخل قارئ التطبيق في النسخة المجانية؛ وفي PRO يمكن تنزيل المصدر إلى مجلد التطبيق ليعمل دون اتصال.

| الوحدة | المراجع المطلوبة | شرط الجودة |
|---|---|---|
| القصص | القرآن، الأنبياء، النساء، الإنسان، الأقوام، الحيوان، وقصص ابن كثير | مصدر واضح ومحتوى غني؛ لا تخترع حقائق دينية. |
| أسباب النزول | تفسير الجلالين ومصدر موثق، بترتيب المصحف | يميز بين النص المرجعي والملخص. |
| الإلهام | `لا تحزن` ومحتوى مرخص/موثق | رسالة مفيدة لا تشخيصية، مع زر تفعيل كل 3 ساعات. |
| قصص المستخدم | حقل كتابة وحاجز أمان | يمنع الكراهية، التنمر، البذاءة، السخرية المفرطة، والإيحاءات الجنسية قبل التحويل إلى فيديو. |
| الفيديو | يولد سيناريو ومشاهد بعد المرور بالحاجز | إنتاج MP4 حقيقي يتطلب مزود فيديو؛ لا يعرض كميزة مكتملة قبله. |

## كارت 5: الألعاب

الشطرنج وروبيك يظلان ضمن ورقة اختيار من اللوحة الرئيسية. تتضمن المرحلة الأولى ساعة شطرنج وتبادل الدور، ثم قواعد حركات قانونية ومحرك منافس. المشهد ثلاثي الأبعاد لا يدّعى قبل اختبار محرك 3D على هاتف Android؛ المكعب يجب أن يتيح تدوير أوجه وحلاً تعليمياً لا مجرد شبكة ألوان.

## كارت 6: الإعدادات وPRO

| الوحدة | مواصفة القبول |
|---|---|
| اللغة | يبدأ التطبيق بلغة الجهاز، ويحفظ آخر اختيار لغة لكل تدفق ترجمة. |
| تنزيلات أوفلاين | قائمة لغات ومصادر مستقلة، شريط تقدم ونسبة وحالة حفظ داخل مساحة التطبيق. |
| PRO | زر ذهبي يقود إلى صفحة كاملة للمزايا والخطط. تعرض الصفحة معرّف تثبيت محلياً وزر نسخ، وحقل باتش موقع وزر لصق، وزر تفعيل أخضر. |
| التحقق | لا يفعّل إلا باتصال إنترنت وتحقق خادمي بتوقيع RSA-SHA256 ووقت خادم موثوق؛ لا يوجد مولّد تراخيص داخل التطبيق. |
| المزايا | صوت المستخدم، مستندات بلا حد، تنزيلات أوفلاين، فيديو القصص، والفقاعة؛ لا تفتح قبل رد خادم صالح. |
| التواصل | تعرض الصفحة معلومات التواصل الرسمية المقدمة من المالك، من دون تضمين بيانات دفع غير مؤكدة في كود التطبيق. |

## حدود الفقاعة العائمة

تُنفذ على Android فقط كخدمة foreground ونافذة overlay بعد إذن صريح. يمكنها قبول نص شاركه المستخدم أو بدأ ترجمته منها؛ لا تقرأ WhatsApp أو البريد أو محتوى الإشعارات تلقائياً ولا تستخدم Accessibility Service. عند الإغلاق لا تحفظ نصوصاً في الحافظة بلا طلب المستخدم.

## ترتيب البناء الإلزامي

تُقبل كل خطوة فقط بعد مرور `flutter pub get` و`flutter analyze` و`flutter test` وبناء APK في GitHub Actions. الترتيب هو: مطابقة اللوحة الرئيسية، محررا الترجمة، مسار المستندات، المحتوى القصصي، ثم التكاملات الأصلية وخدمة PRO. لا يسبق أي محرك ذكاء اصطناعي أو فيديو أو 3D حقيقي استقرار الشاشة والبيانات التي يستخدمها.
