# مواصفة قبول واجهة ووظائف Mirror Scorpion v4 — Flutter/Android

> **النطاق الحاكم.** المنصة النشطة Flutter/Android فقط. لا تُعد الواجهة دليلاً على اكتمال خدمة؛ لا تُقبل أي دفعة قبل `flutter analyze` و`flutter test` وبناء APK في GitHub Actions، ثم قبول Android عند الحاجة إلى ميكروفون أو كاميرا أو واجهة نظام أصلية.

## اللوحة الرئيسية

تتكون الشاشة من هوية Royal Dark، شعار العقرب وانعكاسه، ثم شبكة ثابتة من ستة كروت بالترتيب: ترجمة نصية، حوار مترجم، مستندات وعدسة، قصص وإلهام، ألعاب وتفكير، وإعدادات وPRO. لا تُغيّر هذه الشبكة أو ترتيبها دون مرجع وقبول مرئي.

| عنصر | مواصفة القبول الحالية |
|---|---|
| الشعار والعنوان | عقرب داخل دائرة مضيئة وانعكاس هادئ، مع «ميرور سكربيون» و«حيث تُصنع البدايات». |
| الفقاعة | كبسولة حالة فقط: «الفقاعة فوق التطبيقات: قيد الإعداد». لا يوجد مفتاح مزيف ولا خدمة Overlay مفعلة. |
| الترجمة | العنوان الفرعي «ترجمة محلية + مايك». لا عبارة «100 لغة» أو وعد بترجمة احترافية مضمونة. |
| المستندات | «OCR صور + PDF قيد الإعداد»؛ لا توحي باستخراج أو ترجمة PDF فعليين. |
| القصص | «قصص وإلهام محلي» مع إسناد لكل محتوى قابل للقراءة. |
| الألعاب | «ألعاب وتفكير»، وتعرض الورقة السفلية «شطرنج قانوني» و«روبيك قيد التطوير»؛ لا ادعاء 3D. |

## الترجمة النصية والحوار

لغة مصدر الميكروفون هي لغة الجهاز دائماً. لا توجد قائمة مصدر أو سهم تبديل. لغة الهدف فقط قابلة للتغيير والحفظ وتبدأ بـEnglish. يلتقط المايك عبارات قصيرة من خدمة الجهاز، ثم تمرر إلى ML Kit المحلي؛ وعند غياب لغة جهاز مطابقة أو ظهور تعريب نطقي للغة لاتينية، تظهر رسالة ولا يُنشأ ناتج بديل.

| الوحدة | منفذ الآن | غير منفذ أو بوابة لاحقة |
|---|---|---|
| النص والحوار | محرران كبيران، ترجمة محلية للنص، هدف محفوظ، ميكروفون الجهاز، TTS نظامي، نسخ النص. | تفريغ وترجمة ملفات صوتية، مشاركة ملف صوتي، أصوات مميزة، نسخ صوت. |
| النماذج | تنزيل نماذج ML Kit عند الحاجة وحالة تقدم صريحة. | ضمان كل زوج لغوي أو جودة مهنية ثابتة؛ بعض الأزواج تمر بالإنجليزية. |

## المستندات والعدسة

تلتقط العدسة أو المعرض صورة، وتجري OCR محلياً للنص اللاتيني، ثم تترجمه إلى لغة الهدف المختارة. اختيار PDF متاح فقط للتخزين المحلي وإظهار اسمه؛ لا استخراج صفحات أو ترجمة أو معاينة PDF وهمية. لا يدّعى دعم OCR العربي أو PDF أو ورقة ترجمة أو علامة مائية أو حصة صفحات قبل بناء خط معالجة حقيقي واختباره.

## القصص والإلهام

تقرأ v4 حزمة بداية محلية وحزمة اقتباسات قدمها مالك التطبيق، وتعرض مصدر وإحالة لكل عنصر. لا تُعرض فهارس دينية واسعة أو نصوص من مصادر خارجية حتى تتحقق الحقوق والمصدر. يمكن استيراد JSON يختاره المستخدم، لكنه لا يصبح مصدراً دينياً موثوقاً تلقائياً.

الإلهام فحص محلي اختياري فقط؛ لا مراقبة لرسائل المستخدم أو سلوكه ولا تشخيص. تحويل القصة إلى فيديو، LLM حي، والتنبيه كل ثلاث ساعات تبقى بوابات مستقلة تحتاج مزوداً وموافقة وتكلفة وسياسة حذف واختبار Android.

## الألعاب والإعدادات وPRO

الشطرنج يعمل بقواعد قانونية وقطع ظاهرة، ساعة 1/3/5/10 دقائق، PGN وخصم محلي بسيط. لا يمثل ذلك محرك Elo أو مشهداً 3D. روبيك 3D غير منفذ. صفحة PRO تعرض معرّف تثبيت وحقل باتش وتوضح أن التحقق الخادمي والشراء غير مربوطين؛ لا تقفل خدمة قبل backend وPlay Billing/اختبارات Sandbox.

حزم المحتوى المحلية تحتاج قبل التوسع: `packageId` و`version` و`hash` و`license` و`sourceCitation` وسياسة استيراد وحذف وتحقق. الفقاعة فوق التطبيقات Android-native فقط، بإذن صريح وخدمة foreground وShare/Process Text، ولا تستخدم Accessibility أو Notification Listener ولا تقرأ تطبيقات التواصل تلقائياً.
