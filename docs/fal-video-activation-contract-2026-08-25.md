# عقد تفعيل Fal للفيديو — Mirror Scorpion v4

**الحالة:** تصميم معتمد، لكنه **غير مفعّل ولا يتصل بـFal**.  
**تاريخ المراجعة:** 25 أغسطس 2026.

## القرار التقني الأولي

يُستخدم المسار التجريبي، عند التفعيل المستقبلي فقط، مع نقطة Fal الرسمية:

```text
fal-ai/wan-25-preview/text-to-video
```

اختيار البداية هو فيديو نصي واحد، مدته **5 ثوانٍ** ودقته **480p**، بلا صورة مرجعية وبلا صوت وبلا شخصيات حقيقية. صفحة النموذج تقول إن 480p تُحاسَب حالياً بسعر 0.05 دولار لكل ثانية؛ لذا يبلغ الحد النظري لفيديو تجريبي واحد مدته خمس ثوانٍ 0.25 دولار وفق السعر وقت المراجعة. هذا الرقم **ليس سعراً ثابتاً داخل التطبيق**؛ يجب قراءة السعر الحالي من Fal قبل تشغيل أي وظيفة، لأن الأسعار قابلة للتغيير. [1] [2]

| البند | القرار |
|---|---|
| النموذج الأولي | Wan 2.5 Text-to-Video من Fal. |
| طول الفيديو | 5 ثوانٍ فقط في المرحلة التجريبية. |
| الدقة | 480p فقط لتقليل التكلفة والانتظار. |
| الصوت/الصورة المرجعية | غير مدعومين في النسخة الأولى؛ يقلل ذلك مخاطر الصوت والهوية والحقوق. |
| السر | `FAL_API_KEY` في إعداد خادم فقط؛ لا يظهر في Flutter أو Git أو السجل. |
| حالة البداية | `disabled`؛ الحد المالي الافتراضي صفر، ولا يمكن إنشاء طلب. |
| عدم التخزين | لا نحفظ الفيديو أو المدخلات في تخزين المشروع ضمن المرحلة الأولى؛ تعرض النتيجة المؤقتة فقط بعد سياسة واضحة. |

## الموافقة المطلوبة قبل الإرسال

لا يظهر زر الإرسال إلا بعد تحديد المستخدم عناصر إقرار مستقلة. لا تكفي الموافقة العامة على شروط التطبيق.

| الإقرار | الغرض |
|---|---|
| أملك النص أو أملك حق استخدامه. | حماية حقوق القصة أو السيناريو. |
| لا يتضمن النص أو الصور هوية شخص حقيقي من دون موافقته. | منع الانتحال أو مخالفة الخصوصية. |
| أفهم أن الفيديو مولد بالذكاء الاصطناعي وقد يحتوي أخطاء. | منع عرضه كوثيقة أو حقيقة تاريخية. |
| أوافق على إرسال **النص المختار فقط** إلى Fal لتوليد الفيديو. | موافقة محددة للنطاق. |
| أفهم الحصة المتبقية والحد المقدر قبل الإرسال. | منع المفاجآت المالية. |

سيستمر مرشح السلامة المحلي لقصة المستخدم، ثم يمر الطلب على مرشح الخادم. تحظر سياسة Fal المحتوى غير القانوني والاستغلال والعنف والكراهية والانتحال غير المصرح به ومخالفة الحقوق والخصوصية. [3]

## عقد وظيفة الخادم

يقوم تطبيق Flutter بطلب Firebase Function تابع للتطبيق، ولا يتصل بنطاق Fal مباشرة. لا تقبل الوظيفة طلباً قبل تحقق الشروط التالية: وجود جلسة مستخدم موثوقة عند توفرها، تفعيل المالك للخدمة، وجود المفتاح السري في الخادم، وجود سقف إنفاق موجب، اكتمال إقرارات الموافقة، نجاح مرشحات المحتوى، وبقاء الحصة اليومية/الشهرية.

```text
createVideoJob
  → validate consent + safety + quota + estimated current price
  → create local job (PENDING)
  → submit to Fal queue only if owner enablement is true
  → retain fal_request_id, never the API key

getVideoJob → maps Fal status to local status
cancelVideoJob → requests cancellation at Fal
deleteVideoJob → removes local job metadata
```

تصف Fal دورة الوظيفة بـ`IN_QUEUE` ثم `IN_PROGRESS` ثم `COMPLETED`، وتعطي معرف الطلب وروابط الحالة والنتيجة والإلغاء. الطلب الموجود في الطابور يمكن حذفه فوراً؛ أما الذي بدأ تشغيله فقد يكمل رغم طلب الإلغاء بحسب النموذج. [4]

## حدود البيانات والحذف

نرسل إلى Fal النص اللازم للفيديو فقط، بعد الفحص. لا نرسل سجل القصة الكامل أو رقم تثبيت الجهاز أو صوت المستخدم أو مفاتيح التفعيل. روابط وسائط Fal عامة وقابلة للانتهاء وفق إعدادات انتهاء الوسائط؛ لذلك لا تعرض على الآخرين ولا تحفظ في سجل تحليلي. [4]

لن تُنسخ الملفات إلى Firebase Storage في التجربة الأولى. إذا اختار المستخدم حفظ الفيديو لاحقاً، يجب أن يكون ذلك قراراً مستقلاً يتضمن مكان التخزين ومدة الحذف وقاعدة وصول واضحة.

## مفاتيح التحكم المطلوبة قبل التشغيل الحقيقي

| متغير خادمي | القيمة الافتراضية | السبب |
|---|---|---|
| `FAL_VIDEO_ENABLED` | `false` | يمنع كل اتصال خارجي افتراضياً. |
| `FAL_API_KEY` | غير موجود | لا يمكن التوليد من دون سر خادمي. |
| `FAL_VIDEO_MONTHLY_CAP_USD` | `0` | يمنع أي إنفاق قبل اعتماد المالك. |
| `FAL_VIDEO_DAILY_JOB_LIMIT` | `0` | يمنع إساءة الاستخدام قبل اعتماد الحصة. |

لا نضيف هذه القيم أو المفتاح الآن. يجب أن يحدد المالك سقفاً شهرياً رقمياً قبل تفعيل `FAL_VIDEO_ENABLED`.
